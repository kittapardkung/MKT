# MKT Content Manager

ระบบจัดการคอนเทนต์การตลาด (แดชบอร์ด KPI, ปฏิทินคอนเทนต์, บอร์ดคิวงาน, ตารางคอนเทนต์, คลังไอเดียและแท็ก) — สร้างด้วย Google Apps Script + Google Sheets เป็นฐานข้อมูล

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Index.html` | หน้าเว็บแอปทั้งหมด (UI + client-side JS) |
| `Code.gs` | Apps Script backend — อ่าน/เขียนข้อมูลใน Google Sheets, ส่งอีเมลแจ้งเตือน, และเสิร์ฟหน้าเว็บผ่าน `doGet()` |
| `appsscript.json` | ไฟล์ manifest ของโปรเจกต์ |

## วิธีติดตั้ง

1. สร้าง Google Sheet ใหม่ (ไฟล์นี้จะเป็นฐานข้อมูล) — **แนะนำให้สร้างสคริปต์แบบผูกกับชีต (bound script)**
2. เปิด **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดตัวอย่างเริ่มต้น แล้วสร้างไฟล์ตามตารางด้านบน คัดลอกเนื้อหาจากรีโปนี้ไปวาง
   - ไฟล์ manifest ให้เปิดผ่านเมนู **Project Settings → Show "appsscript.json" manifest file in editor** ก่อน จึงจะแก้ไขได้จากใน Apps Script editor
4. แก้ค่าคอนฟิกด้านบนของ `Code.gs`:
   - **`TEAM`** — กำหนดสิทธิ์รายอีเมล เช่น `'name@company.com': 'editor'` คนที่ไม่อยู่ในลิสต์จะเป็น `creative` โดยอัตโนมัติ
   - **`NOTIFY_EMAILS`** — อีเมลที่จะรับสรุปประจำสัปดาห์และแจ้งเตือนงานรออนุมัติ ถ้าเว้นว่างไว้ระบบจะส่งหา `editor` ทุกคนใน `TEAM` แทน
5. ในแท็บ Apps Script editor เลือกฟังก์ชัน **`setupApp`** แล้วกด Run (ครั้งแรกจะขอ authorize สิทธิ์การเข้าถึงชีต/อีเมล/ตัวจับเวลา) — ฟังก์ชันนี้จะ:
   - สร้างชีต `Posts`, `Ideas`, `Tags`, `Events`, `Targets`, `Log` พร้อม header และข้อมูลตั้งต้น (เป้าหมาย KPI, แท็กตัวอย่าง)
   - ตั้ง time-based trigger สองตัว: `remindPending` (ทุกวัน 09:00 แจ้งงานรออนุมัติ) และ `weeklyDigest` (ทุกวันจันทร์ 08:00 สรุป KPI 7 วัน)
6. **Deploy → New deployment → Web app**
   - Execute as: **User accessing the web app**
   - Who has access: ตามนโยบายทีม (เช่น เฉพาะคนในองค์กร Google Workspace หรือ Anyone with the link ที่ต้องล็อกอิน Google)
   - กด Deploy แล้วแชร์ลิงก์ที่ได้ให้ทีม
7. **สำคัญ**: ผู้ใช้แต่ละคนต้องมีสิทธิ์ **Editor** บน Google Sheet นี้ด้วย (แชร์ไฟล์ชีตให้ทีม) เพราะเว็บแอปรันด้วยสิทธิ์ของผู้ใช้ที่เข้าถึง (`executeAs: USER_ACCESSING`) การอ่าน/เขียนข้อมูลจึงต้องอาศัยสิทธิ์บนตัวชีตจริง

### กรณีต้องการรันสคริปต์แบบไม่ผูกกับสเปรดชีต (standalone script)

ตั้ง Script Property ชื่อ `SPREADSHEET_ID` เป็น ID ของ Google Sheet ที่ต้องการใช้เป็นฐานข้อมูล (Project Settings → Script Properties) — `db_()` จะอ่านค่านี้ก่อนเสมอ ถ้าไม่พบจึงจะ fallback ไปใช้ `SpreadsheetApp.getActiveSpreadsheet()`

## Sheets ที่ระบบใช้งาน

ระบบจะสร้าง/ซ่อมโครงชีตให้อัตโนมัติทุกครั้งที่เรียก API (`ensureSheets()`) โดยเติมเฉพาะคอลัมน์ที่ขาดไว้ด้านขวา ไม่ทับข้อมูลเดิม:

- **Posts** — คอนเทนต์ทั้งหมด (`id,date,time,channel,title,format,status,owner,caption,tags,src_link,final_link,approved_by,approved_at,post_url`) สถานะที่รองรับ: ร่าง / รออนุมัติ / อนุมัติแล้ว / เผยแพร่แล้ว
- **Ideas** — คลังไอเดียที่ยังไม่ถูกส่งเข้าปฏิทิน (`promoted_post_id` จะถูกเติมเมื่อส่งเข้าปฏิทินแล้ว)
- **Tags** — แท็กที่ใช้กับคอนเทนต์ (คอลัมน์ `active` ใช้สำหรับซ่อน/ลบแบบ soft delete)
- **Events** — กิจกรรม Event Test Drive ใช้คำนวณ KPI
- **Targets** — เป้าหมาย KPI แต่ละตัว (คีย์: `leads`, `content`, `video`, `image`, `events`)
- **Log** — ประวัติทุกการเปลี่ยนแปลง (สร้าง/แก้ไข/เปลี่ยนสถานะ/อนุมัติ/คอมเมนต์) พร้อมผู้ทำรายการและเวลา
- **GET_tel** *(ไม่ได้สร้างอัตโนมัติ)* — ชีตข้อมูลลีดจากฝ่ายขาย (เช่นผ่าน `IMPORTRANGE`) ต้องมีคอลัมน์ `Created_Date`, `Phone_Number`, `Source`, `Interested_Model`, `Lead_Status` ระบบจะนับลีดไม่ซ้ำจากเบอร์โทรศัพท์ให้อัตโนมัติในแดชบอร์ด ถ้าไม่มีชีตนี้หรือคอลัมน์ไม่ครบ ระบบจะแสดงค่าลีดเป็น 0 โดยไม่ error

## สิทธิ์การใช้งาน (Role)

กำหนดผ่านตัวแปร `TEAM` ใน `Code.gs` (ไม่ใช้ชีตแยก):

- **editor** — เห็นปุ่ม "อนุมัติ" และกดอนุมัติคอนเทนต์ที่สถานะ "รออนุมัติ" ได้ (ฝั่งเซิร์ฟเวอร์ตรวจสิทธิ์ซ้ำอีกชั้นก่อนอนุมัติจริง) และเป็นผู้รับอีเมลแจ้งเตือน/สรุปประจำสัปดาห์โดยอัตโนมัติ (เว้นแต่กำหนด `NOTIFY_EMAILS` แยกไว้)
- **creative** — ค่าเริ่มต้นของทุกอีเมลที่ไม่อยู่ใน `TEAM` — สร้าง/แก้ไขคอนเทนต์ ไอเดีย และแท็กได้ตามปกติ แต่ไม่เห็นปุ่มอนุมัติ

## การแจ้งเตือนอัตโนมัติ

ตั้งค่าผ่าน `createTriggers()` (เรียกจาก `setupApp()`):

- เมื่อคอนเทนต์ถูกเปลี่ยนสถานะเป็น "รออนุมัติ" จะส่งอีเมลแจ้ง editor ทันที
- ทุกวัน 09:00 — สรุปงานที่ยังค้างรออนุมัติทั้งหมด (`remindPending`)
- ทุกวันจันทร์ 08:00 — สรุป KPI ย้อนหลัง 7 วัน (`weeklyDigest`)

## โฟลเดอร์ต้นฉบับรายเดือน (ไม่บังคับ)

เมื่อสร้างคอนเทนต์ใหม่โดยไม่ได้ระบุ `src_link` ระบบจะพยายามเติมลิงก์โฟลเดอร์ Google Drive ประจำเดือนให้อัตโนมัติ โดยอ่านจาก Script Property ชื่อ `DRIVE_FOLDER_yyyy_MM` (เช่น `DRIVE_FOLDER_2026_08`) — ถ้าไม่ได้ตั้งค่าไว้ ช่องนี้จะว่างเปล่าและกรอกเองภายหลังได้
