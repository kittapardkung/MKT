# MKT Content Manager

ระบบจัดการคอนเทนต์การตลาด (แดชบอร์ด KPI, ปฏิทินคอนเทนต์, บอร์ดคิวงาน, ตารางคอนเทนต์, คลังไอเดียและแท็ก) — สร้างด้วย Google Apps Script + Google Sheets เป็นฐานข้อมูล

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Index.html` | หน้าเว็บแอปทั้งหมด (UI + client-side JS) |
| `Code.gs` | Apps Script backend — อ่าน/เขียนข้อมูลใน Google Sheets และเสิร์ฟหน้าเว็บผ่าน `doGet()` |
| `appsscript.json` | ไฟล์ manifest ของโปรเจกต์ |

## วิธีติดตั้ง

1. สร้าง Google Sheet ใหม่ (ไฟล์นี้จะเป็นฐานข้อมูล)
2. เปิด **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดตัวอย่างเริ่มต้น แล้วสร้างไฟล์ตามตารางด้านบน คัดลอกเนื้อหาจากรีโปนี้ไปวาง
   - ไฟล์ manifest ให้เปิดผ่านเมนู **Project Settings → Show "appsscript.json" manifest file in editor** ก่อน จึงจะแก้ไขได้จากใน Apps Script editor
4. บันทึกโปรเจกต์ แล้วรีโหลดหน้า Google Sheet — จะเห็นเมนูใหม่ **MKT Content**
5. กดเมนู **MKT Content → ตั้งค่าเริ่มต้น (Initialize Sheets)** เพื่อสร้างชีตข้อมูลทั้งหมดพร้อมข้อมูลตั้งต้น (`Posts`, `Tags`, `Ideas`, `Events`, `Targets`, `Leads`, `Users`, `Log`)
   - ชีต `Users` จะใส่อีเมลของคุณเป็น role `editor` ให้อัตโนมัติในแถวแรก — เพิ่มอีเมลคนอื่นในทีมพร้อมกำหนด role เป็น `editor` หรือ `creative` ได้จากชีตนี้โดยตรง
6. **Deploy → New deployment → Web app**
   - Execute as: **User accessing the web app**
   - Who has access: ตามนโยบายทีม (เช่น เฉพาะคนในองค์กร หรือ Anyone with the link ที่ต้องล็อกอิน Google)
   - กด Deploy แล้วแชร์ลิงก์ที่ได้ให้ทีม
7. **สำคัญ**: ผู้ใช้แต่ละคนต้องมีสิทธิ์ **Editor** บน Google Sheet นี้ด้วย (แชร์ไฟล์ชีตให้ทีม) เพราะเว็บแอปรันด้วยสิทธิ์ของผู้ใช้ที่เข้าถึง (`executeAs: USER_ACCESSING`) การอ่าน/เขียนข้อมูลจึงต้องอาศัยสิทธิ์บนตัวชีตจริง

### กรณีต้องการรันสคริปต์แบบไม่ผูกกับสเปรดชีต

หากดีพลอยเป็น standalone script ที่ไม่ได้ผูกกับสเปรดชีตโดยตรง ให้ตั้งค่า Script Property `SPREADSHEET_ID` เป็น ID ของ Google Sheet ที่ต้องการใช้เป็นฐานข้อมูล (Project Settings → Script Properties)

## Sheets ที่ระบบใช้งาน

- **Posts** — คอนเทนต์ทั้งหมด (สถานะ: ร่าง / รออนุมัติ / อนุมัติแล้ว / เผยแพร่แล้ว)
- **Tags** — แท็กที่ใช้กับคอนเทนต์ (คอลัมน์ `active` ใช้สำหรับซ่อน/ลบแบบ soft delete)
- **Ideas** — คลังไอเดียที่ยังไม่ถูกส่งเข้าปฏิทิน (`promoted_post_id` จะถูกเติมเมื่อส่งเข้าปฏิทินแล้ว)
- **Events** — กิจกรรม Event Test Drive ใช้คำนวณ KPI
- **Targets** — เป้าหมาย KPI แต่ละตัว (`leads`, `content`, `video`, `image`, `events`)
- **Leads** — ข้อมูลลีดที่เข้ามา (แหล่งที่มา, รุ่นที่สนใจ) ใช้สรุปในแดชบอร์ด
- **Users** — กำหนด role ของแต่ละอีเมล (`editor` อนุมัติคอนเทนต์ได้, ที่เหลือถือเป็น `creative`)
- **Log** — บันทึกคอมเมนต์/เหตุการณ์ที่แนบมากับการบันทึก หรืออนุมัติคอนเทนต์แต่ละครั้ง

## สิทธิ์การใช้งาน (Role)

- **editor** — เห็นปุ่ม "อนุมัติ" และกดอนุมัติคอนเทนต์ที่สถานะ "รออนุมัติ" ได้ (ทั้งฝั่งเซิร์ฟเวอร์ตรวจสิทธิ์ซ้ำอีกชั้นก่อนอนุมัติจริง)
- **creative** — สร้าง/แก้ไขคอนเทนต์ ไอเดีย และแท็กได้ตามปกติ แต่ไม่เห็นปุ่มอนุมัติ

กำหนด role ได้จากชีต `Users` (คอลัมน์ `email`, `role`)
